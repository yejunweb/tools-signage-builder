## 3. 功能

对照 PRD：

### 3.1 列表与历史

- [ ] 打开应用进入列表
- [ ] 新建 / 点卡片编辑 / 复制（默认名「原名 - 副本」）/ 删除（二次确认文案符合 PRD）
- [ ] 按记录名搜索后分页；本机 JSON 历史读写正常（`version: 1`）
- [ ] 卡片预览图为保存时生成并随记录存储，列表只读展示

### 3.2 编辑与默认值

- [ ] 新建默认：名称 `YYYY-MM-dd hh:mm:ss 创建的记录`；宽 400 / 高 100 / 圆角 15；底色 `#ef7296`；展示类型全选；楼栋号、楼层数空；房号**空列表**，点新增加行
- [ ] `buildingNum` / `totalFloorNum` 为记录级各一份；各自可配字色 + 描边
- [ ] 房号列表：每条单元号 + 室号 + 面积；增删；**拖拽排序**；每字段各自字色 + 描边
- [ ] 展示类型：栋 / 层 / 单元 / 房 / 面积多选，驱动绘制行显隐
- [ ] 底栏：透明底默认勾选；取消 / 导出 PNG / 保存；未保存返回可拦截

### 3.3 绘制、预览与导出

- [ ] 绘制对齐 `generateSignTexture`：完整牌典型四行；行 2、3 单元格合并规则正确
- [ ] 表单宽高即 canvas 像素；导出同尺寸
- [ ] 实时预览随表单更新；导出仅为标牌本体；默认文件名与记录名一致并加 `.png`
- [ ] 透明底开 / 关导出结果符合 PRD（圆角外透明 / 白）

### 3.4 数据字段

- [ ] 单条含 PRD §6 约定字段（含 `transparentBackground` 默认 `true`、`showTypes`、`showInfoLs`、预览 dataURL、时间戳等）
- [ ] 宽高合法范围与失焦回退符合 PRD 建议

## 5. 交付物与自检

实现在**云端**完成；验收不依赖本机逐步跑开发过程，以交付物为准：

| 交付 | 要求 |
| --- | --- |
| 代码 / PR | 可检出、可按仓库说明构建；变更说明覆盖本期范围 |
| 设计对照 | 实现帧与 Magic OS / spec 一致（可附截图） |
| 自检 | 构建通过；上表 UI / 功能 / 规范 checklist 自测勾选结果可复述 |
| 运行产物 | 可安装或可运行的一期包 / 开发构建说明，便于抽查列表、编辑、导出 |

抽查建议：新建默认 → 填楼栋/层与 1～3 条房号 → 预览四行与合并 → 导出透明底开/关 → 保存回列表 → 复制 / 删除 / 搜索分页。
